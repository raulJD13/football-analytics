# Frontend — React + TypeScript

## Stack
- React + TypeScript
- Recharts for charts
- Fetch from FastAPI at http://localhost:8000

## Key views
- /standings  → clasificación actual + proyectada
- /teams/:id  → stats detalladas de equipo
- /predict    → widget predicción home vs away

## Conventions
- One component per file
- API calls in src/api/ hooks
- No inline styles — use CSS modules
